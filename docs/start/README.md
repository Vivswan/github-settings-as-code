# Start

For someone bringing a first repository under this action, or moving one off the Probot Settings app. Read these before the guides under [Operate](../operate/README.md); the [reference pages](../reference/README.md) specify what each section does.

- [Getting started](getting-started.md): one repository from nothing to a settings file applied on every change: the token, the settings file and the workflow, check mode first, then apply.
- [Migrating from the Probot Settings app](migrating-from-probot.md): what to expect, in what order to do things, and how to read the first check run.
- [Examples](examples.md): a cookbook of settings.yml files, each validated in CI. It shows shapes, not behavior.
- [Command line](cli.md): the same engine as a command, `github-settings-as-code` or `gsac`, from a terminal or any CI, plus `init`, validating a settings file, and printing the PAT grant it needs.
